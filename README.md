# Customer Churn Prediction

## Project Overview
This is a Machine Learning project that predicts whether a customer is likely to leave (churn) or stay based on customer information.

## Features
- Data preprocessing
- Machine Learning model training
- Customer churn prediction
- Command-line interface
- Model saved using Joblib

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Project Structure

customer-churn-prediction/
│
├── data/

└── .gitignore

## How to Run

1. Clone the repository

```
git clone <repository-link>
```

2. Install dependencies

```
pip install -r requirements.txt
```

3. Run the project

```
cd src
python predict.py
```

## Sample Output

```
Prediction: Customer will CHURN
```

or

```
Prediction: Customer will NOT CHURN
```
